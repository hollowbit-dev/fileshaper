Mein GitHub

Warum ich Filesmith gebaut habe

Ein Video für Discord verkleinern, ein iPhone-Foto unter Windows öffnen, ein PDF unterschreiben: Fast jeder muss das irgendwann. Die übliche Lösung ist eine Website, die deine Dateien hochladen lässt, dich warten lässt und Geld fürs Entfernen eines Wasserzeichens will.

Das fand ich falsch für Aufgaben, die ein normaler Computer in Sekunden erledigt. Also habe ich Filesmith gebaut: eine App für Video, Bilder, PDF und Audio, die komplett auf deinem eigenen Computer läuft.

Ich habe sie gestaltet, den Code geschrieben, die Installationsprogramme für Windows und Mac gebaut, diese Website erstellt und 21 automatisierte Tests geschrieben, die die echte App steuern und jedes Werkzeug prüfen.

Woran sich Hollowbit hält

Keine Werbung
Weder in der App noch auf der Website.
Keine Konten
Für eine Dateiumwandlung braucht man keine Anmeldung.
Kein Tracking
Keine Analysen und keine Datensammlung.
Open Source
Jede Zeile Code ist öffentlich.

Wie es gebaut ist

Electron

Eine Codebasis für Windows und Mac

FFmpeg

Video-, Audio- und Bildverarbeitung

pdf-lib und PDF.js

PDFs bearbeiten, unterschreiben und darstellen

Zwei-Pass-Kodierung

Landet knapp unter der Zielgröße

Playwright

21 End-to-End-Tests an der echten App

Keine Netzwerkaufrufe

Funktioniert ohne WLAN

Filesmith

Jede Datei reparieren. Nichts verlässt deinen Computer.
