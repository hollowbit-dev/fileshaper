Datenschutzerklärung

Zuletzt aktualisiert am 11. November 2026

Kurz gesagt: Filesmith sammelt nichts. Deine Dateien verlassen nie deinen Computer.

Die App

Filesmith verarbeitet jede Datei auf deinem eigenen Computer. Es gibt kein Konto, keine Analysen und keine Absturzberichte. Die einzige Netzwerkverbindung ist eine optionale Update-Prüfung: Einmal am Tag fragt Filesmith bei GitHub die neueste Versionsnummer ab und sendet nichts über dich oder deine Dateien. Du kannst sie in den Einstellungen ausschalten. Deine Einstellungen und die Liste erstellter Dateien liegen auf deinem Computer; den Verlauf kannst du jederzeit löschen.

Diese Website

Diese Website wird auf GitHub Pages gehostet. GitHub kann gemäß seiner eigenen Datenschutzerklärung übliche Serverprotokolle wie IP-Adressen speichern. Die Website setzt keine Cookies und nutzt weder Analysen noch Tracking. Schriftarten liegen hier und werden nicht von Google geladen. Deine Sprachwahl wird nur in deinem Browser gespeichert.

Trinkgeld

Wenn du auf Ko-fi ein Trinkgeld gibst, wickelt Ko-fi die Zahlung nach seiner eigenen Datenschutzerklärung ab. Filesmith sieht deine Zahlungsdaten nie.

Kontakt

Fragen zum Datenschutz? Eröffne ein Issue auf GitHub.
