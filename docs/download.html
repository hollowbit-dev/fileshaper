Download Fileshaper.

Free, with no account. Pick your computer.

Version 1.2.1 · Released 11 November 2026

Windows

Windows 10 or 11, 64-bit

Download for Windows
  1. Run the installer you downloaded.
  2. If you see “Windows protected your PC”, click More info.
  3. Click Run anyway. You only do this once.

macOS

macOS 12 Monterey or newer

Apple SiliconIntel

Not sure which Mac you have? Open the Apple menu, then About This Mac. “Apple M1”, M2, M3 or M4 means Apple Silicon.

  1. Open the .dmg and drag Fileshaper into Applications.
  2. Right-click Fileshaper in Applications and choose Open.
  3. Click Open. If macOS still blocks it, go to System Settings, Privacy & Security, and click Open Anyway.

Opening it the first time

Fileshaper is new and isn't signed with a paid developer certificate yet, so your computer shows a warning the first time. This is how to open it safely.
