Mi GitHub

Por qué existe Filesmith

Reducir un vídeo para Discord, abrir una foto de iPhone en Windows, firmar un PDF: casi todo el mundo tiene que hacerlo. La respuesta habitual es una web que te pide subir tus archivos, esperar en una cola y pagar para quitar una marca de agua.

Me pareció mal para tareas que un ordenador normal hace en segundos. Filesmith es la respuesta: una app para vídeo, imágenes, PDF y audio que funciona entera en tu propio ordenador.

Incluye instaladores para Windows y Mac, esta web y 21 pruebas automáticas que manejan la app real para comprobar que cada herramienta funciona.
