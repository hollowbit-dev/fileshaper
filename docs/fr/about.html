Pourquoi Fileshaper existe

Réduire une vidéo pour Discord, ouvrir une photo d'iPhone sous Windows, signer un PDF : presque tout le monde doit le faire. La réponse habituelle, c'est un site qui vous demande d'envoyer vos fichiers, d'attendre dans une file et de payer pour retirer un filigrane.

Ça m'a semblé absurde pour des tâches qu'un ordinateur normal fait en quelques secondes. Fileshaper est la réponse : une app pour la vidéo, les images, les PDF et l'audio qui tourne entièrement sur votre ordinateur.

Elle est livrée avec des programmes d'installation pour Windows et Mac, ce site et 21 tests automatisés qui pilotent la vraie app pour vérifier chaque outil.
