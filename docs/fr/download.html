Télécharger

Téléchargez Filesmith.

Gratuit, sans compte. Choisissez votre ordinateur.

Version 1.0.0 · Publiée le 10 novembre 2026

Windows

Windows 10 ou 11, 64 bits

Télécharger pour Windows
  1. Lancez le programme d'installation téléchargé.
  2. Si « Windows a protégé votre ordinateur » apparaît, cliquez sur Informations complémentaires.
  3. Cliquez sur Exécuter quand même. C'est à faire une seule fois.

macOS

macOS 12 Monterey ou plus récent

Apple SiliconIntel

Vous ne savez pas quel Mac vous avez ? Ouvrez le menu Pomme, puis À propos de ce Mac. « Apple M1 », M2, M3 ou M4 signifie Apple Silicon.

  1. Ouvrez le .dmg et faites glisser Filesmith dans Applications.
  2. Faites un clic droit sur Filesmith dans Applications et choisissez Ouvrir.
  3. Cliquez sur Ouvrir. Si macOS bloque encore, allez dans Réglages Système, Confidentialité et sécurité, puis Ouvrir quand même.

La première ouverture

Filesmith est récent et pas encore signé avec un certificat de développeur payant, donc votre ordinateur affiche un avertissement la première fois. Voici comment l'ouvrir en toute sécurité.
