Politique de confidentialité

Dernière mise à jour : 11 novembre 2026

En bref : Fileshaper ne collecte rien. Vos fichiers ne quittent jamais votre ordinateur.

L'app

Fileshaper traite chaque fichier sur votre propre ordinateur. Il n'a ni compte ni statistiques et n'envoie aucun rapport de plantage. La seule connexion est une vérification facultative des mises à jour : une fois par jour, il demande à GitHub le numéro de la dernière version, sans rien envoyer sur vous ou vos fichiers. Vous pouvez la désactiver dans les Réglages. Vos réglages et la liste des fichiers créés restent sur votre ordinateur, et vous pouvez effacer l'historique à tout moment.

Ce site

Ce site est hébergé sur GitHub Pages. GitHub peut conserver des journaux de serveur classiques, comme les adresses IP, selon sa propre politique de confidentialité. Le site n'utilise ni cookies, ni statistiques, ni pistage. Les polices sont hébergées ici, pas chargées depuis Google. Votre choix de langue est mémorisé uniquement dans votre navigateur.

Pourboires

Si vous laissez un pourboire sur Ko-fi, Ko-fi gère le paiement selon sa propre politique de confidentialité. Fileshaper ne voit jamais vos données de paiement.

Contact

Une question sur la confidentialité ? Ouvrez un ticket sur GitHub.
