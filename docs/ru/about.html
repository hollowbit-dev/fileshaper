Мой GitHub

Зачем существует Filesmith

Уменьшить видео для Discord, открыть фото с iPhone в Windows, подписать PDF — это нужно почти всем. Обычно для этого предлагают сайт, куда надо загрузить файлы, подождать в очереди и заплатить за удаление водяного знака.

Мне это показалось неправильным для задач, которые обычный компьютер решает за секунды. Filesmith — ответ: одно приложение для видео, изображений, PDF и аудио, которое полностью работает на вашем компьютере.

В комплекте установщики для Windows и Mac, этот сайт и 21 автоматический тест, который управляет настоящим приложением и проверяет каждый инструмент.

Принципы Hollowbit

Без рекламы
Ни в приложении, ни на сайте.
Без аккаунтов
Чтобы конвертировать файл, регистрация не нужна.
Без слежки
Никакой аналитики и сбора данных.
Открытый код
Каждая строка кода публична.
