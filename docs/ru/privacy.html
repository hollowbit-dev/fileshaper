Политика конфиденциальности

Обновлено 11 ноября 2026 года

Коротко: Fileshaper ничего не собирает. Ваши файлы никогда не покидают компьютер.

Приложение

Fileshaper обрабатывает каждый файл на вашем компьютере. У него нет аккаунтов и аналитики, он не отправляет отчёты о сбоях. Единственное сетевое обращение — необязательная проверка обновлений: раз в день он узнаёт у GitHub номер последней версии и ничего не отправляет о вас и ваших файлах. Её можно отключить в настройках. Настройки и список созданных файлов хранятся на вашем компьютере, историю можно очистить в любой момент.

Этот сайт

Сайт размещён на GitHub Pages. GitHub может хранить обычные журналы сервера, например IP-адреса, согласно своей политике конфиденциальности. Сайт не использует cookie, аналитику и отслеживание. Шрифты размещены здесь, а не загружаются из Google. Выбранный язык запоминается только в вашем браузере.

Чаевые

Если вы оставите чаевые на Ko-fi, платёж обрабатывает Ko-fi по своей политике конфиденциальности. Fileshaper никогда не видит ваши платёжные данные.
