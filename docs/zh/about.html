我为什么做 Filesmith

为 Discord 压缩视频、在 Windows 上打开 iPhone 照片、签署 PDF，几乎每个人都会遇到。通常的办法是找个网站，上传文件、排队等待，再付钱去掉水印。

对于普通电脑几秒钟就能完成的事，我觉得这样不对。所以我做了 Filesmith：一个处理视频、图片、PDF 和音频的应用，完全在你自己的电脑上运行。

我设计了它，写了代码，打包了 Windows 和 Mac 安装程序，做了这个网站，还写了 21 个自动化测试，直接操作真实应用来检查每个工具。
