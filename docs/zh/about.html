为什么会有 Fileshaper

为 Discord 压缩视频、在 Windows 上打开 iPhone 照片、签署 PDF，几乎每个人都会遇到。通常的办法是找个网站，上传文件、排队等待，再付钱去掉水印。

对于普通电脑几秒钟就能完成的事，我觉得这样不对。Fileshaper 就是答案：一个处理视频、图片、PDF 和音频的应用，完全在你自己的电脑上运行。

它提供 Windows 和 Mac 安装程序、这个网站，以及 21 个直接操作真实应用、检查每个工具的自动化测试。
