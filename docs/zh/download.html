Windows

Windows 10 或 11，64 位

下载 Windows 版
  1. 运行你下载的安装程序。
  2. 如果看到“Windows 已保护你的电脑”，点击“更多信息”。
  3. 点击“仍要运行”。只需要做一次。

macOS

macOS 12 Monterey 或更新版本

Apple 芯片Intel

不确定你的 Mac 是哪种？打开苹果菜单，选择“关于本机”。显示“Apple M1”、M2、M3 或 M4 就是 Apple 芯片。

  1. 打开 .dmg，把 Filesmith 拖进“应用程序”。
  2. 在“应用程序”中右键点击 Filesmith，选择“打开”。
  3. 点击“打开”。如果 macOS 仍然阻止，前往“系统设置”中的“隐私与安全性”，点击“仍要打开”。

第一次打开

Filesmith 还很新，尚未使用付费开发者证书签名，所以第一次打开时电脑会显示警告。按以下步骤即可安全打开。
