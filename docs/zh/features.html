Filesmith 能做的一切。

十八个工具，覆盖视频、图片、PDF 和音频。每个都是像“小于 10 MB”或“转成 JPG”这样简单的选择，而不是一整页设置。

视频图片PDF音频

视频

选一个大小上限，Filesmith 每次都刚好压在它下面。

  • 按大小压缩8、10、16、25 或 50 MB，或自定义数值。长视频会降低分辨率，依然清晰。
  • 按画质压缩高、均衡或最小，适合不在意大小的时候。
  • 剪辑在预览上拖动两个滑块，只保留你想要的部分。
  • 制作 GIF选几秒钟，设定流畅度和宽度。
  • 提取音频把任何视频的声音保存为 MP3。
  • 转换为 MP4MOV、MKV、WEBM 和 AVI 都能转成到处都能播放的 MP4。
  • 去除声音画面保持不变，只去掉音频。

图片

在 Windows 上打不开的 iPhone 照片，批量搞定。

  • 转换HEIC、PNG、WebP、GIF、BMP 和 TIFF 转为 JPG、PNG 或 WebP。
  • 调整尺寸按最长边或百分比，照片绝不会被拉伸。
  • 压缩文件更小，看起来一样，随时可以发送或上传。
  • 图片转 PDF每张图片一页，方向自动摆正。

PDF

平时要付费、或者要上传文件才能做的 PDF 事务。

  • 签署与填写手写或输入签名，添加姓名和日期，拖到合适的位置。
  • 合并按任意顺序合并 PDF。
  • 拆分逐页、按范围，或只取你选的页面。
  • 整理页面拖动缩略图来重新排序、旋转和删除页面。
  • 压缩轻度压缩保留可选中的文字，强力压缩适合扫描件和图片多的文件。

音频

语音备忘、播客、歌曲和铃声。

  • 转换MP3、M4A、WAV、FLAC 和 OGG。
  • 剪辑剪出铃声或语音备忘里最精彩的一段，可预览。
  • 统一音量小声的录音变大，大声的变小，达到流媒体应用的标准响度。

每个工具都有

随手拖入

把文件拖到窗口任意位置，Filesmith 会自动分好视频、照片、PDF 和音频。

命令栏

按 Ctrl K（Mac 上是 ⌘K），输入你想做的事，比如“heic 转 jpg”。

批量处理

一次处理上百个文件，每个都显示进度。

原文件安全

每个结果都是新文件，原文件永远不会被改动。

节省一目了然

每个结果都显示处理前后的大小。

深色与浅色

默认深色，可在设置中切换浅色或跟随系统。
