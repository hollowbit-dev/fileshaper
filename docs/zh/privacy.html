隐私政策

最后更新：2026 年 11 月 11 日

简而言之：Filesmith 不收集任何信息。你的文件从不离开你的电脑。

应用

Filesmith 在你自己的电脑上处理每个文件。它没有账号、没有统计分析，也不发送崩溃报告。唯一的网络请求是可选的更新检查：每天向 GitHub 查询一次最新版本号，不会发送任何关于你或你文件的信息。你可以在设置中关闭它。你的设置和已生成文件的列表保存在你的电脑上，随时可以清除历史记录。

本网站

本网站托管在 GitHub Pages 上。GitHub 可能会依据其隐私政策保留常规服务器日志，例如 IP 地址。本网站不使用 Cookie，也不使用任何统计或跟踪。字体由本站托管，不从 Google 加载。你选择的语言只保存在你的浏览器中。

打赏

如果你在 Ko-fi 上打赏，付款由 Ko-fi 按其隐私政策处理。Filesmith 永远看不到你的支付信息。

联系

对隐私有疑问？请在 GitHub 上提交 issue。

Filesmith

修好任何文件。文件绝不离开你的电脑。
